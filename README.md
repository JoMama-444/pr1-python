# Система регистрации сервисных обращений

## Назначение
Приложение для регистрации и учёта обращений клиентов в сервисный центр.

## Целевая аудитория
Клиенты сервисного центра, мастера, администраторы приёмки.

## Предметная область
Сервисное обслуживание: приём устройств, назначение мастеров, учёт обращений.

## Основные сущности
- Клиент
- Устройство
- Обращение
- Мастер

## Основные функции
- Регистрация нового обращения
- Проверка доступности мастера
- Просмотр списка обращений

## План развития
- Разработка веб-приложения
- Подключение базы данных
- Реализация пользователей
- Разработка API
- Контейнеризация приложения
- Настройка CI/CD
